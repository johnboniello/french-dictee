## Full description

I built French Dictée Practice for my own daughter, to help her practice her weekly French spelling words at home.

The app includes three practice modes. Lettres mélangées presents the letters of a word out of order, to be put back in place. Le bon mot presents the correct spelling among a set of choices. Dictée sur papier reads a word aloud, to be written out on paper, the traditional way a dictée is practiced in a French classroom.

A word list can be typed in directly, or scanned from a photo using the camera. That photo is processed entirely on the device, so it is never uploaded anywhere.

Progress is tracked automatically. Words that are missed are flagged for extra review, and correct answers are met with a small animation, so practice stays encouraging rather than repetitive.

An optional sync feature allows the same word list to be shared across devices, using a randomly generated code rather than an account or email address. This makes it possible for a child to practice on more than one device, or for a parent or grandparent to review the same list, without creating a login.

There are no ads, no required accounts, and no tracking. I built this to be a simple, focused tool for a real need in my own house, and I am glad to share it in case it helps yours as well.
